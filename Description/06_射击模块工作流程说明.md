# 射击模块工作流程说明

## 1. 模块定位

射击模块代码位于：

- `Code/ChaseNum1_Shooter.c`
- `Code/ChaseNum1_Shooter.h`

它只负责一次射击动作本身：摩擦轮启动、等待预热、总线舵机推弹、关闭摩擦轮、舵机回位。上位机不直接控制 PWM 和舵机细节，只通过 NANO 协议发送 `FIRE`、`RESET`、`GET_STATE`。

## 2. 硬件分配

| 功能 | 引脚/外设 | 说明 |
| --- | --- | --- |
| 摩擦轮 PWM | `PB8 / TIM16_CH1` | 输出到 DRV8701 的 PWM 输入 |
| 摩擦轮方向 | `PB7` | 输出到 DRV8701 的 DIR 输入 |
| 推弹舵机 | `UART5` | 使用和机械臂相同格式的总线舵机协议 |
| UART5 TX | `PB13` | 射击舵机总线发送 |
| UART5 RX | `PB12` | 当前只初始化接收，射击流程不依赖读取 |

`PB8` 已确认不再被底盘占用。`Code/ChaseNum1_Shooter.c` 内部单独封装了 UART5 舵机发包，不修改 `ChaseNum1_BusServo.c/.h`。

## 3. 重要宏定义

主要参数集中在 `Code/ChaseNum1_Shooter.h`：

| 宏 | 默认值 | 含义 |
| --- | ---: | --- |
| `SHOOTER_PWM_PERIOD_COUNT` | `10000` | PWM 自动重装载计数，占空比计数范围 |
| `SHOOTER_PWM_DEFAULT_DUTY` | `6000` | 摩擦轮启动后的默认占空比计数 |
| `SHOOTER_DIR_FORWARD_LEVEL` | `GPIO_PIN_SET` | 摩擦轮正转时 PB7 电平，方向反了改这里 |
| `SHOOTER_SERVO_ID` | `1` | 推弹总线舵机 ID |
| `SHOOTER_SERVO_HOME_POS` | `0` | 舵机初始位置，单位 0.1 度 |
| `SHOOTER_SERVO_PUSH_POS` | `900` | 舵机推弹位置，单位 0.1 度 |
| `SHOOTER_SERVO_SPEED` | `900` | 舵机速度，单位 0.1 度/秒 |
| `SHOOTER_SPINUP_MS` | `800` | 摩擦轮预热时间 |
| `SHOOTER_SERVO_EXTRA_WAIT_MS` | `300` | 舵机动作估算后的额外等待裕量 |
| `SHOOTER_RESET_EXTRA_WAIT_MS` | `500` | reset 回位额外等待裕量 |
| `SHOOTER_ACTION_TIMEOUT_MS` | `5000` | 一次动作最大允许时间 |

这些参数也被列入 `NANO_Control/communication.yml`，方便上位机侧记录和调试。

## 4. 初始化流程

`USER/main.c` 在气泵初始化后调用：

```c
Shooter_Init();
```

初始化动作：

1. 清空射击模块内部状态。
2. 初始化 `PB7` 为方向输出，并设置为正转方向。
3. 初始化 `PB8` 为 `TIM16_CH1` PWM 输出。
4. 初始化 `UART5`。
5. 关闭摩擦轮 PWM。
6. 给射击舵机发送回初始位置命令。

初始化不阻塞等待舵机到位，只发送回位命令。

## 5. 状态机流程

射击模块状态：

| 状态 | 值 | 含义 |
| --- | ---: | --- |
| `IDLE` | 0 | 空闲 |
| `SPINUP` | 1 | 摩擦轮预热中 |
| `PUSHING` | 2 | 舵机推弹中 |
| `RETURNING` | 3 | 舵机回初始位置中 |
| `RESETTING` | 4 | 复位中 |
| `FAULT` | 5 | 故障预留 |

一次射击流程：

```text
IDLE
  -> Shooter_Start()
  -> 打开摩擦轮 PWM
  -> SPINUP 等待 SHOOTER_SPINUP_MS
  -> 舵机运动到 SHOOTER_SERVO_PUSH_POS
  -> PUSHING 等待估算运动时间
  -> 关闭摩擦轮 PWM
  -> 舵机回 SHOOTER_SERVO_HOME_POS
  -> RETURNING 等待估算运动时间
  -> IDLE，并产生 SHOOTER_EVENT_DONE
```

整个过程由 `Shooter_Task_Loop()` 非阻塞推进，不使用延时函数。

## 6. reset 流程

`Shooter_Reset()` 会立即：

1. 关闭摩擦轮 PWM。
2. 发送舵机回 `SHOOTER_SERVO_HOME_POS` 命令。
3. 进入 `RESETTING`。
4. 等待估算时间后回到 `IDLE`，产生 `SHOOTER_EVENT_RESET_DONE`。

系统 `RESET` 和 `ESTOP` 都会调用 `Shooter_Reset()`，因此整机复位或急停时摩擦轮会被关闭。

## 7. 舵机发包

射击舵机使用高级单圈速度位置控制命令 `0x0C`。发包格式和机械臂总线舵机一致：

```text
0x12 0x4C CMD LEN CONTENT CHECK
```

其中：

```text
CHECK = sum(0x12, 0x4C, CMD, LEN, CONTENT...) & 0xFF
```

`CONTENT` 长度为 11：

```text
uint8  servo_id
int16  position
uint16 speed
uint16 accel
uint16 decel
uint16 power
```

当前只发送命令，不读取舵机真实位置；逻辑位置由代码估算和记录。

## 8. NANO 协议

射击模块 ID：

```text
MODULE_SHOOTER = 0x05
```

命令：

| 命令 | 值 | 载荷 |
| --- | ---: | --- |
| `SHOOTER_FIRE` | `0x40` | 空 |
| `SHOOTER_RESET` | `0x41` | 空 |
| `SHOOTER_GET_STATE` | `0x42` | 空 |

事件：

| 事件 | 值 | 含义 |
| --- | ---: | --- |
| `SHOOTER_DONE` | `0x40` | 一次射击完成 |
| `SHOOTER_RESET_DONE` | `0x41` | 射击模块复位完成 |
| `SHOOTER_TIMEOUT` | `0x42` | 射击动作超时 |

状态回包 `SHOOTER_STATE 0x88`：

```text
uint8 shooter_state
uint8 friction_on
uint8 busy
uint8 reserved
float duty_percent
int16 servo_pos
uint16 pwm_duty
```

## 9. 上位机调用

Python controller 位于：

```text
NANO_Control/controller.py
```

常用方法：

```python
ctl.shooter_fire()
ctl.shooter_reset()
ctl.shooter_get_state()
```

一次射击示例：

```python
from controller import NanoController

with NanoController(port="COM8", auto_open=True) as ctl:
    ctl.system_hello()
    seq_or_ack = ctl.shooter_fire()
    event = ctl.wait_for_event(event_code=0x40, timeout_s=6)
    ctl.shooter_get_state()
```

图形界面 `NANO_Control/nano_protocol_ui.py` 中有“射击”卡片，可以直接点击“射击 / 复位 / 读取”。

## 10. 调试注意事项

1. 如果摩擦轮方向反了，优先修改 `SHOOTER_DIR_FORWARD_LEVEL`。
2. 如果射击力度不足，优先调大 `SHOOTER_PWM_DEFAULT_DUTY`，但不要超过 `SHOOTER_PWM_PERIOD_COUNT`。
3. 如果舵机没推到位，检查 `SHOOTER_SERVO_PUSH_POS`、`SHOOTER_SERVO_SPEED` 和 `SHOOTER_SERVO_EXTRA_WAIT_MS`。
4. 如果上位机收到 `SHOOTER_TIMEOUT`，说明状态机超过 `SHOOTER_ACTION_TIMEOUT_MS` 仍未完成，通常是等待参数设置过大或主循环被阻塞。
5. 当前没有读取舵机真实位置，所有“到位”判断都基于时间估算。
