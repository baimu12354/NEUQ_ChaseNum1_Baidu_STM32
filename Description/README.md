# ChaseNum1 工程说明文档

本目录用于给后续接手工程的同学快速理解当前下位机工程。文档按照功能模块拆分，每份报告都尽量从“代码入口、核心变量、状态流转、上位机视角、调参点和注意事项”几个角度说明。

建议阅读顺序：

1. `01_底盘运动流程说明.md`：理解底盘四种运动模式、闭环执行和上位机变量映射。
2. `02_机械臂运动流程说明.md`：理解机械臂坐标定义、逆解、禁区、规划器和舵机下发。
3. `03_菜单显示说明.md`：理解 TFT 状态页每一行含义，以及如何用屏幕判断通信/主循环是否异常。
4. `04_气泵工作流程说明.md`：理解 PE5 PWM、PE6 测频、滤波、吸附判定和协议事件。
5. `05_整机状态机与通讯协议说明.md`：理解 NANO 统一协议帧格式、命令、回包、系统状态机和 Python 上位机接口。
6. `06_射击模块工作流程说明.md`：理解 PB8 摩擦轮 PWM、PB7 方向、UART5 推弹舵机和射击协议。

本文档只描述当前代码实现，不额外改变任何外设功能。若后续修改了宏定义、协议字段或状态机逻辑，应同步更新本目录对应报告。
