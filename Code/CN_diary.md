# 此文件为 2026届 百度“智慧农场” 下位机工程日志

_2026.4.22 ~ 2026.4.23_ {
    
    1. 移植 RC 遥控器
    2. 重构底盘运动功能，建立底盘运动状态机
        包括四个状态：Breaking = 0,   // 休息状态 
                     Running,        // 运行状态
                     Rotation,       // 旋转状态
                     Translation     // 定点平移状态
        状态机流程如下：
            Breaking状态下车模处于开环状态
            Running状态下车模处于闭环状态（支持纵向速度闭环、横向速度闭环、角速度闭环以及角度闭环，车模航向姿态具有抗干扰性）
            Rotation状态下车模可以 定角 定速 旋转（支持旋转任意圈数，达到目标角度后默认返回Running状态）
            Translation状态下车模可以 定向 定点 定速 平移（平移过程中航向姿态保持不变、达到目标角度后默认返回Running状态）

}

_2026.5.12 ~ 2026.5.13_ {

    改进机械臂解算

    1.更改解算方式：根据上位机需求传入吸盘末端的空间坐标与吸盘在竖直平面内的方向，直接解算出目标位置
    2.优化运动路径：为了克服机械臂运动过程中遇到障碍，对机械臂的运动路径做了状态规划：收敛-旋转-展开，
      并且依据运动速度计算到达目标位置的时间，流畅地实现了状态转换
    3.机械臂偶然会出现重新上电后角度突变的情况，还需要多加测试
    4.目前这版符合上位机要求，等待与上位机一起标定后再做修改

}

_2026.6.6 ~ 2026.6.7_ {

      一是改 单字节解析 为 软件缓冲区队列+定时器轮询解析，避免上位机高频发送导致下位机串口中断冲突卡死；
